# Personal Portfolio Website

A modern, responsive personal portfolio website developed using HTML5, CSS3, and JavaScript as part of the **Progree Full Stack Development Internship**.

The portfolio showcases my background, technical skills, academic projects, and contact information through a clean and user-friendly interface.

## Live Website

**Portfolio:** https://hanigaba22.github.io/progree-portfolio/

## Features

- Fully responsive design for desktop, tablet, and mobile devices
- Modern dark-themed user interface
- Interactive mobile navigation menu
- Smooth navigation between sections
- About Me and Technical Skills sections
- Academic and personal project showcase
- Email, GitHub, and LinkedIn contact links

## Technologies Used

- **HTML5** — Semantic webpage structure
- **CSS3** — Styling, Flexbox, Grid, and media queries
- **JavaScript** — Interactive navigation and dynamic functionality
- **GitHub** — Source code hosting and version control
- **GitHub Pages** — Website deployment

## Website Sections

**Home:** Introduction and professional overview.

**About:** Educational background and interests.

**Skills:** Programming languages, web development technologies, and design skills.

**Projects:** Academic and personal development projects.

**Contact:** Professional contact information and social profile links.

## Responsive Design

The website uses CSS Flexbox, Grid, and media queries to adapt its layout to different screen sizes. A hamburger navigation menu is provided for smaller screens.

## Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional dependencies or installation are required.
